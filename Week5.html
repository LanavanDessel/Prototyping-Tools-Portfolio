Netlify en GitHub

Lana van Dessel - 1GDM1

Datum: 6 november 2025

In deze les leerden we hoe we onze website online kunnen zetten met Netlify en hoe we GitHub gebruiken om onze bestanden te bewaren en bij te werken. Zo hoeven we niet alles steeds handmatig te uploaden en kunnen we onze website makkelijk updaten.

Wat ik heb gedaan

Tijdens de les maakte ik een GitHub-repository waarin ik mijn HTML-, CSS- en andere bestanden kon opslaan. Daarna leerde ik hoe ik deze repository aan Netlify kon koppelen, zodat mijn website automatisch wordt bijgewerkt wanneer ik nieuwe bestanden toevoeg.

Aan het einde stond mijn website online via een Netlify-link. Zo kan ik mijn werk eenvoudig delen met anderen.

Reflectie

Ik vond het leuk om te leren hoe je een website echt online zet. Het voelde bijzonder, omdat mijn werk nu niet alleen op mijn laptop stond.

In het begin vond ik GitHub lastig door termen zoals commits, branches en repositories. Maar door oefenen werd het duidelijker en bespaart het me nu veel tijd.

De volgende keer wil ik leren hoe ik meerdere pagina’s beter kan beheren en hoe ik snel fouten kan oplossen als Netlify of GitHub niet werkt.
